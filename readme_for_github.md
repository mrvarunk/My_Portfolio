## 🏛️ Architectural Overview

Unlike typical portfolios that rely on generic templates, this project was architected from first principles as an **interactive engineering console**. It bridges the gap between raw systems engineering rigor (Java 21, Kafka, Redisson distributed locks, PostgreSQL pgvector) and modern front-end motion physics (3D perspective tilt, real-time matrix decryption, raytraced cursor spotlights).

### Key Architectural Highlights:
- **100% Pure Front-End**: Completely decoupled from backend servers; compiles to an ultra-fast, static, zero-runtime artifact deployable anywhere (Vercel, Netlify, Cloudflare Pages, GitHub Pages).
- **Sub-Second Build Performance**: Built with Vite 8 and React 19, compiling in **<750ms** with zero TypeScript errors.
- **Accessible & Screen-Reader Verified**: WCAG 2.1 AA compliant color contrast, semantic HTML5 tags, keyboard navigation traps for modals, and ARIA attributes.
- **Embedded Interactive Terminal (⌘K / Ctrl+K)**: Fully functional in-browser terminal emulator that interprets diagnostic commands, queries project specs, and triggers modals.

### 1. Aesthetic Philosophy & Color Science

The visual language draws inspiration from **industrial developer tooling** (Linear, Raycast, Stripe Developer Dashboard, Bloomberg Terminal). The canvas eliminates stark pure blacks (`#000000`) in favor of rich, layered obsidian tones to prevent OLED smearing and reduce eye strain during prolonged inspection.

#### The Tri-Tone Semantic Color System:
| Token Name | Hex Code | Role & Psychological Purpose |
|---|---|---|
| **System Primary** | `#8083ff` / `#c0c1ff` | **Architectural Foundation**: Used for primary CTAs, GitGPT vectors, and structural highlights. Conveys engineering precision. |
| **Telemetry Secondary** | `#4edea3` / `#6ffbbe` | **Uptime & Algorithmic Rigor**: Used for live status beacons, CodeChef ratings, high-throughput metrics, and success states. |
| **Intelligence Tertiary** | `#4cd7f6` / `#acedff` | **Real-Time Data & Latency**: Used for network latency indicators, LeetCode Knight stats, and AST token streaming badges. |
| **Void Base** | `#121318` / `#0d0e13` | **Substrate**: Absorptive, non-reflective base with ultra-low luminance contrast fatigue. |
| **Precision Borders** | `rgba(255, 255, 255, 0.08 - 0.18)` | **Micro-Structure**: Hairline borders defining containment without visual clutter. |

### 2. Typography Hierarchy

The typography pairs technical legibility with geometric elegance across three specialized typeface families:

1. **`Geist` (Headlines & Display)**:
   - Engineered by Vercel specifically for technical developer dashboards.
   - Features precise geometric apertures, high x-height, and razor-sharp numerals at large display scales (`4xl` to `56px`).
2. **`Inter` (Body & Narrative Copy)**:
   - Optically calibrated for variable screen densities.
   - Set with relaxed line heights (`leading-relaxed`) in neutral surface tints (`#c7c4d7` and `#e3e1e9`) to maximize reading speed.
3. **`JetBrains Mono` (Code, Badges, Labels & Telemetry)**:
   - Monospace font designed for code reading with distinct punctuation glyphs and tabular numeral alignment.
   - Used for all system latency indicators, contest ratings, tech stack badges, and the CLI console.

### 3. Motion Choreography & Kinetic Physics

All animations are implemented through hardware-accelerated CSS and **Motion v12** (GPU transform/opacity layers only, guaranteeing steady 60–120 FPS performance):

```
Page Load
  │
  ├──► 1. Ambient Particle Orbs Float & Breathe (Looping 10s-12s Ease)
  ├──► 2. Availability Radar Beacon Fires (Pulsing Ping Effect)
  ├──► 3. Cyber Decrypt Scramble: "Hi, I'm Varun K." (Resolves at 1000ms)
  ├──► 4. Equalizer Frequency Bars Oscillate (Live Soundwave Telemetry)
  ├──► 5. Liquid Gradient Wave Sweeps Across Tagline (Continuous Shader)
  ├──► 6. Rotating Dual Gradient Ring Around Profile Photo (12s Linear)
  └──► 7. Telemetry Numbers Count Up (Cubic Ease-Out Counter)
```

#### Key Motion Paradigms:
1. **Matrix / Cyber-Scramble Decrypt (`useScrambleText`)**:
   - On initial mount, `"Hi, I'm Varun K."` rapidly cycles through high-tech ASCII glyphs (`0 1 α β █ ▓ ░ & % $ # * @ !`) before snapping to clean letterforms.
   - Interactive: Users can click the name to re-trigger the decryption cascade.
2. **Kinetic Liquid Gradient (`animate-flowing-gradient`)**:
   - The tagline `"I engineer scalable distributed backends & AI systems."` features a multi-stop flowing aurora gradient across `#e1e0ff` → `#4cd7f6` → `#4edea3` → `#c0c1ff`, accented by an oscillating cybernetic node (`◈`).
3. **Dynamic Specialization Rotator**:
   - Smoothly slides between core technical specialties every 3.5 seconds using spring transitions (`AnimatePresence mode="wait"`).
4. **Interactive 3D Mouse Parallax Tilt**:
   - Project cards track real-time cursor coordinates relative to card geometry, executing responsive 3D perspective transforms (`rotateX`, `rotateY`, `scale3d`) with subtle spring damping.
5. **Raytraced Cursor Proximity Spotlight**:
   - An illumination spotlight (`radial-gradient`) follows the cursor position across cards, casting dynamic reflections over dark brushed surfaces.
6. **Cybernetic Laser Scanline (`animate-cyber-scan`)**:
   - Hovering over any project screenshot activates an animated neon laser beam that sweeps vertically across the image.

## 🚀 Featured Systems & Projects

Each production system featured on the portfolio highlights deep technical problems, architectural trade-offs, and concrete benchmarks:

### 1. GitGPT — Full-Stack RAG Codebase Assistant
- **Domain**: AI / Distributed Knowledge Engine
- **Latency Benchmark**: `LATENCY < 850ms` (720ms average end-to-end)
- **Core Architecture**:
  - Semantic vector search with **PostgreSQL + pgvector** using HNSW cosine distance indexing over Abstract Syntax Trees (ASTs).
  - Real-time chunking and token streaming to **Google Gemini API** via reactive Spring Boot endpoints.
  - Interactive visualization in React with token cost analytics and context branch navigation.
- **Tech Stack**: `Java 21`, `Spring Boot 3`, `PostgreSQL (pgvector)`, `Google Gemini API`, `React`
- **Repository**: [github.com/mrvarunk/gitgpt](https://github.com/mrvarunk/gitgpt)

### 2. Distributed Web Crawler & Search Indexer
- **Domain**: Cloud & High-Throughput Concurrency
- **Concurrency Model**: `Java 21 Project Loom (Virtual Threads)`
- **Core Architecture**:
  - 10,000+ lightweight carrier-thread agnostic workers executing non-blocking HTTP requests.
  - Decoupled URL frontier coordinator via **Amazon SQS FIFO** queues with polite domain rate limiting.
  - In-memory **Bloom filter deduplication** (7 hash functions, O(1) rejection, `<0.01%` false positive rate).
  - Inverted search indices stored across **Amazon DynamoDB** with sub-5ms lookup latency.
- **Tech Stack**: `Java 21`, `Amazon SQS`, `Amazon S3`, `Amazon DynamoDB`, `Docker`, `Jsoup`
- **Repository**: [Distributed-Web-Crawler-Search-Indexer](https://github.com/mrvarunk/Distributed-Web-Crawler-Search-Indexer)

### 3. MicroCommerce — Event-Driven Microservices
- **Domain**: High-Concurrency Distributed E-Commerce
- **Consistency Guarantee**: `0-Oversold Race Condition Tolerance`
- **Core Architecture**:
  - Distributed mutex synchronization via **Redis (Redisson distributed locks)** with automated watchdog lease renewals.
  - Asynchronous event bus on **Apache Kafka** with partitioned topic routing across Order, Inventory, Payment, and Notification services.
  - Fault-tolerant Dead-Letter Queue (DLQ) topology preventing catastrophic cascade failures during traffic spikes.
  - Concurrency stress-tested with 50+ simultaneous purchases using JUnit 5 and `CountDownLatch`.
- **Tech Stack**: `Java`, `Spring Boot`, `Apache Kafka`, `Redis (Redisson)`, `Kubernetes`, `JUnit 5`
- **Repository**: [MicroCommerce](https://github.com/mrvarunk/MicroCommerce)

### 4. Cafe Ops — Enterprise Multi-Tenant POS Platform
- **Domain**: Enterprise SaaS & Data Isolation
- **Security Standard**: `Zero IDOR Vector Leaks`
- **Core Architecture**:
  - Stateless RSA-signed JWT authentication with Spring Security context filters injecting tenant claims into `ThreadLocal` storage.
  - Automatic row-level schema isolation through Hibernate entity interceptors appending tenant predicates to all SQL queries.
  - Dynamic modifier trees serialized into PostgreSQL `JSONB` with two-tier caching in Redis (94.2% hit ratio).
  - Asynchronous mutation telemetry and audit logging via **Spring AOP**.
- **Tech Stack**: `Java`, `Spring Boot`, `Spring Security`, `PostgreSQL JSONB`, `Redis`, `GitHub Actions`
- **Repository**: [CafeOps-Enterprise-Multi-Tenant-POS-System](https://github.com/mrvarunk/CafeOps-Enterprise-Multi-Tenant-POS-System)

## ⚡ Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- `npm`, `pnpm`, or `yarn`

### 1. Clone the repository
```bash
git clone https://github.com/mrvarunk/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Run tests & type checks
```bash
npm run lint       # TypeScript strict no-emit validation
npx tsx src/utils/systemLogic.test.ts # Unit tests
```

### 5. Production build
```bash
npm run build      # Produces optimized static output in /dist
npm run preview    # Preview production bundle locally
```

## 🌐 Live Deployment

Because this project is a **100% pure client-side React application**, the `/dist` directory can be deployed with zero configuration on:

- **Vercel**: Import repository → Framework preset: *Vite* → Deploy.
- **GitHub Pages**: Build with `npm run build` and push `/dist` to `gh-pages` branch.
- **Netlify**: Set build command `npm run build` and publish directory `dist`.
- **Cloudflare Pages**: Connect git repository and set output to `dist`.
